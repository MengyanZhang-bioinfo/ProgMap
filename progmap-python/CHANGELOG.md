# Changelog

## 0.1.0 - 2026-07-25

- Initial public release of the ProgMap 2048-128 skip-model implementation.
- Added stratified outer cross-validation and nested epoch selection.
- Added configurable early stopping, fold counts, training parameters, learning rate, and random seed.
- Added fold-specific Pearson and Spearman expression-methylation correlation.
- Added enhanced integrated-gradient attribution and configurable feature testing.
- Added progress reporting, pooled out-of-fold metrics, audit tables, and detailed feature output.
- Added Linux requirements, a Conda environment, CPU and GPU Dockerfiles, and Slurm support.
- Added a generic synthetic example, automated tests, and an Ubuntu continuous-integration workflow.
